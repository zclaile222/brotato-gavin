> 但**实际上玩家侧当时完全没有状态效果系统**。因此新建了 `scripts/PlayerStatus.gd`
> （燃烧 / 减速 / 眩晕，含眩晕冷却与「刷新不累加」语义）。详见主状态文档 §7.11。
>
> **已完成 —— 第 4、5、6 条**（P4-5 的 P2，2026-09-16）：
> 三个变体的独特机制已落地，`Enemy._physics_process()` 的 Boss 分支按 `enemy_type`
> 分派到 `_process_fire_boss()` / `_process_frost_boss()` / `_process_lightning_boss()`：
> - **火焰**：冲锋（阶段1 起）+ 沿路径按间距留下 `BurnZone`（新场景）+ 阶段2 烈焰光环；
> - **冰霜**：冰甲 5s 开 / 4s 关循环（阶段2 常驻）+ 阶段2 冻结脉冲（1s 蓄力预警）；
> - **雷电**：闪现传送 + 链式闪电子弹 + 阶段2 雷暴领域（0.8s 预警圈 + 延迟落雷）。
>
> 覆盖测试：`tests/boss_mechanics_smoke.gd`（每条机制都有正向 + 反向断言）。
>
> **实现时对本文档做的两处偏离**（都是有意的，理由如下）：
> 1. §2.3 的「冻结」写成 `apply_freeze()`，但**玩家侧没有这个 API**（只有敌人身上有）。
>    玩家侧的「冻结」用 `PlayerStatus.apply_stun(1.5)` 表达 —— 它自带 1.0s 冷却，
>    这是防止弹幕把玩家锁死的有意设计，不可绕过。效果上等价（1.5s 无法行动）。
> 2. §3.3 的链式闪电写「命中后向最近**敌人**位置弹射」——那是玩家侧武器的语义。
>    敌方视角下唯一的目标就是玩家，「最近的另一个目标」退化成了玩家自己，
>    所以实现为「对同一目标连续打击」：命中后从玩家周围的随机方向再飞回来一次，
>    每跳递减 `chain_remaining`。起点刻意放在 200px 外，否则会被玩家的 0.8s 无敌帧整发挡掉。
>
> **尚未实现**：§2.3 阶段1 的「寒冰光环」（附近敌人获得 20% 减速抗性）。
> 本文档自己标注为「可选实现，优先级低」，且它需要一套敌人侧的减速抗性属性，
> 与「三个 Boss 打起来不一样」这个目标无关，故留到后续。
> §1.5 / §2.5 / §3.5 的视觉打磨（粒子、屏幕闪烁）属 P3，未做。

## 设计目标

在现有 Boss 系统基础上，新增 3 个元素主题 Boss 变体。每个变体保留基础 Boss 的 3 阶段系统框架，但拥有独特的元素机制，使战斗体验差异化。

参考基础数据（来自 `scripts/Enemy.gd`）：

| 类型 | spd | hp_m | sc | color | xp | dmg | dist | gold |
|------|-----|------|----|-------|----|-----|------|------|
| boss | 50 | 10.0 | 2.4 | (1.0, 0.55, 0.0) | 20 | 2 | 0 | 30 |
| miniboss | 45 | 6.0 | 2.0 | (0.8, 0.3, 0.1) | 12 | 2 | 0 | 18 |

## 1. 火焰 Boss（Flame Emperor）

### 1.1 数据定义

```
"boss_fire": {
    "spd": 55,
    "hp_m": 9.0,
    "sc": 2.4,
    "color": Color(1.0, 0.3, 0.0),   # 橙红色
    "xp": 22,
    "dmg": 2,
    "dist": 0,
    "gold": 32
}
```

### 1.2 设计理念

火焰 Boss 是**进攻型**变体。相比基础 Boss 稍快、血量略低，但攻击频率更高，且拥有地面燃烧区域的场地控制能力。玩家需要持续移动来躲避地面火焰，同时应对 Boss 的弹幕。

### 1.3 三阶段行为

#### 阶段 0 — 正常（HP > 75%）

| 机制 | 详情 |
|------|------|
| 移动 | 追踪玩家，速度 55 |
| 弹幕射击 | 5 发扇形火焰弹，间隔 1.8s，子弹颜色橙红 |
| 火焰环 | 每 3.5s 发射 8 方向火焰弹（类似 _shoot_spiral） |
| 接触伤害 | 2 点 |

#### 阶段 1 — 强化（HP <= 75%）

| 机制 | 详情 |
|------|------|
| 速度提升 | +25%（base_speed *= 1.25） |
| 弹幕射击 | 8 发扇形火焰弹，间隔 1.2s |
| 火焰环 | 每 2.5s 发射 12 方向火焰弹 |
| 新机制：火焰冲锋 | 每 4s 向玩家方向冲锋，冲锋路径留下燃烧区域（持续 3s，踩上去触发 apply_burn） |
| 阶段切换特效 | 橙红色爆炸 + 屏幕闪烁 |

#### 阶段 2 — 狂暴（HP <= 15%）

| 机制 | 详情 |
|------|------|
| 速度提升 | 累计 +50%（base_speed *= 1.2，叠加阶段1） |
| 弹幕射击 | 狂暴连发：8 方向 x3 连发（复用 _shoot_rage_burst），间隔 0.8s |
| 火焰环 | 每 1.5s 发射 16 方向火焰弹 |
| 火焰冲锋 | 每 2.5s 冲锋，路径燃烧区域持续 5s |
| 新机制：烈焰光环 | Boss 周围 80px 范围内持续产生燃烧效果（玩家靠近即触发 apply_burn） |

### 1.4 需要新增的代码机制

- ✅ **火焰冲锋**：类似 charger 的冲刺逻辑，冲刺路径上每隔一定间距（`BURN_ZONE_SPACING = 40px`）生成燃烧区域节点
- ✅ **燃烧区域**：`scenes/BurnZone.tscn` + `scripts/BurnZone.gd`，持续时间可配置，玩家进入后触发 `apply_burn`
- ✅ **烈焰光环**：阶段 2 时在 `_process_fire_boss()` 中检测与玩家的距离（`FIRE_AURA_RADIUS = 80px`），近距离时调用 `PlayerStatus.apply_burn()`

> 实现注记：冲锋只在阶段 1 起出现（与本文档「阶段1 新机制」的定位一致），
> 冲锋方向在起步那一帧锁定，之后不再跟随玩家 —— 否则会变成无法躲开的追踪冲刺。
> 燃烧区域用**每物理帧轮询重叠体**而不是 `body_entered` 信号：冲锋可能把火直接生成在
> 玩家脚下，此时进入树就已重叠，信号不会触发。区域内重新施加燃烧有 0.5s 节流，
> 否则逐帧刷新会让玩家在火里永远不会烧完（等于持续掉血）。

### 1.5 视觉规格

- Boss 本体：橙红色（1.0, 0.3, 0.0），受击闪白后恢复
- 子弹颜色：橙红色（1.0, 0.4, 0.0）
- 燃烧区域：半透明橙色圆形（1.0, 0.5, 0.0, alpha 0.4），脉冲动画
- 阶段切换：橙红色死亡爆炸特效 + Boss 颜色加深（阶段1: 1.0, 0.2, 0.0，阶段2: 0.9, 0.1, 0.0）

## 2. 冰霜 Boss（Ice Tyrant）

### 2.1 数据定义

```
"boss_frost": {
    "spd": 40,
    "hp_m": 12.0,
    "sc": 2.6,
    "color": Color(0.4, 0.7, 1.0),   # 蓝白色
    "xp": 24,
    "dmg": 2,
    "dist": 0,
    "gold": 35
}
```

### 2.2 设计理念

冰霜 Boss 是**控制型**变体。速度最慢但血量最高、体型最大。核心机制是减速和冻结，迫使玩家在受限的移动能力下应对弹幕。战斗节奏缓慢但压迫感极强。

### 2.3 三阶段行为

#### 阶段 0 — 正常（HP > 75%）

| 机制 | 详情 |
|------|------|
| 移动 | 追踪玩家，速度 40（最慢 Boss） |
| 弹幕射击 | 5 发扇形冰弹，间隔 2.0s，子弹颜色蓝白 |
| 冰霜新星 | 每 4s 发射 12 方向冰弹（速度较慢，飞行中留下冰晶轨迹） |
| 接触伤害 | 2 点 |
| 被动效果 | 子弹命中玩家时触发 apply_slow(0.3, 2.0)（减速 30% 持续 2s） |

#### 阶段 1 — 强化（HP <= 75%）

| 机制 | 详情 |
|------|------|
| 速度提升 | +15%（base_speed *= 1.15） |
| 弹幕射击 | 7 发扇形冰弹，间隔 1.5s |
| 冰霜新星 | 每 3s 发射 16 方向冰弹 |
| 新机制：冰甲 | 复用 armor_value 系统，获得 30% 伤害减免，持续 5s 后消失，4s 后重新获得（循环） |
| 新机制：寒冰光环 | Boss 周围 120px 范围内的所有敌人获得 20% 减速抗性（buff，不减速玩家） |
| 阶段切换特效 | 蓝白色爆炸 + 冰晶粒子扩散 |

#### 阶段 2 — 狂暴（HP <= 15%）

| 机制 | 详情 |
|------|------|
| 速度提升 | 累计 +30%（base_speed *= 1.13，叠加阶段1） |
| 弹幕射击 | 狂暴连发：8 方向 x3 连发（冰弹版），间隔 0.9s |
| 冰霜新星 | 每 2s 发射 20 方向冰弹 |
| 冰甲 | 常驻（永久 30% 伤害减免） |
| 新机制：冻结脉冲 | 每 5s 释放一次全屏冻结脉冲，对玩家触发 apply_freeze()（1.5s 冻结），有 1s 蓄力预警动画 |

### 2.4 需要新增的代码机制

- **冰弹减速效果**：需要在 EnemyBullet 中增加元素类型标识，命中玩家时根据类型触发不同状态效果（P1 已完成）
- ✅ **冰甲循环**：`_process_frost_boss()` 用计时器控制 `armor_value` 的开关（`FROST_ARMOR_REDUCTION = 30`、开 5s / 关 4s，阶段2 常驻）
- ✅ **冻结脉冲**：阶段2 每 5s 一次，带 1s 蓄力预警（`_freeze_charge`，颜色向纯白渐变）+ 全屏范围检测；
  玩家侧没有 `apply_freeze()`，用 `apply_stun(1.5)` 表达（见文档开头的偏离说明）
- ⬜ **寒冰光环**：对附近敌人应用 buff 的逻辑（本文档自己标注为可选、优先级低，本次未做 —— 需要先有敌人侧的减速抗性属性）

### 2.5 视觉规格

- Boss 本体：蓝白色（0.4, 0.7, 1.0），体型最大（sc: 2.6）
- 子弹颜色：浅蓝色（0.5, 0.8, 1.0）
- 冰甲激活时：Boss 外围显示半透明白色护盾轮廓
- 冻结脉冲蓄力：Boss 颜色在 1s 内渐变为纯白，然后爆发蓝白色环形波
- 阶段切换：蓝白色死亡爆炸 + 冰晶碎片粒子

## 3. 雷电 Boss（Thunder Lord）

### 3.1 数据定义

```
"boss_lightning": {
    "spd": 65,
    "hp_m": 8.0,
    "sc": 2.2,
    "color": Color(0.9, 0.9, 0.2),   # 黄紫色（主色黄，辅色紫）
    "xp": 25,
    "dmg": 3,
    "dist": 0,
    "gold": 35
}
```

### 3.2 设计理念

雷电 Boss 是**机动型**变体。速度最快、伤害最高但血量最低、体型最小。核心机制是位移和眩晕，战斗节奏极快，玩家需要快速反应。Boss 会频繁传送改变位置，配合链式闪电攻击。

### 3.3 三阶段行为

#### 阶段 0 — 正常（HP > 75%）

| 机制 | 详情 |
|------|------|
| 移动 | 追踪玩家，速度 65（最快 Boss） |
| 弹幕射击 | 5 发扇形雷弹，间隔 1.6s，子弹颜色黄色 |
| 链式闪电 | 每 2.5s 发射 1 发特殊子弹，命中后向最近敌人位置弹射 1 次（链式效果） |
| 接触伤害 | 3 点（最高） |

#### 阶段 1 — 强化（HP <= 75%）

| 机制 | 详情 |
|------|------|
| 速度提升 | +30%（base_speed *= 1.3） |
| 弹幕射击 | 6 发扇形雷弹，间隔 1.2s |
| 链式闪电 | 每 1.5s 发射 1 发，命中后弹射 2 次 |
| 新机制：闪现 | 每 3.5s 传送到玩家附近随机位置（100-200px 范围），传送瞬间释放 8 方向雷弹 |
| 阶段切换特效 | 黄紫色爆炸 + 闪电弧特效 |

#### 阶段 2 — 狂暴（HP <= 15%）

| 机制 | 详情 |
|------|------|
| 速度提升 | 累计 +50%（base_speed *= 1.15，叠加阶段1） |
| 弹幕射击 | 狂暴连发：8 方向 x3 连发（雷弹版），间隔 0.7s |
| 链式闪电 | 每 1s 发射 1 发，命中后弹射 3 次 |
| 闪现 | 每 2s 传送，传送瞬间释放 12 方向雷弹 |
| 新机制：雷暴领域 | 每 4s 在玩家当前位置降下雷击（延迟 0.8s 的范围攻击，有预警圈），造成 3 点伤害 + 0.5s 眩晕 |

### 3.4 需要新增的代码机制

- ✅ **链式闪电**：`EnemyBullet.chain_remaining` + `_spawn_chain_hop()` —— 命中玩家后再从附近方向飞回来一次，
  每跳递减（敌方视角下唯一目标就是玩家，见文档开头的偏离说明）
- ✅ **闪现传送**：`_blink()` 直接设置 position 到玩家周围 100–200px + 触发 `_shoot_spiral`
- ✅ **雷暴领域**：`_storm_pending` 延迟落雷队列（0.8s 预警圈 + 范围检测），命中造成伤害 + `apply_stun(0.5)`；
  预警期内跑出范围即不受伤害
- ✅ **眩晕接触**：由玩家侧的 `PlayerStatus` 统一施加（元素子弹已带 `lightning`），未额外硬编码接触眩晕

### 3.5 视觉规格

- Boss 本体：黄色（0.9, 0.9, 0.2）为主，阶段切换时短暂变为紫色（0.6, 0.2, 0.8）
- 子弹颜色：亮黄色（1.0, 1.0, 0.3）
- 闪现特效：原位置和新位置同时出现紫色闪电弧
- 雷暴领域预警：地面紫色圆圈，0.8s 后黄色闪电劈下
- 阶段切换：黄紫色爆炸 + 放射状闪电线条

## 通用实现方案

### ENEMY_TYPES 新增条目

在 `scripts/Enemy.gd` 的 `ENEMY_TYPES` 字典中添加：

```gdscript
"boss_fire":      {"spd": 55, "hp_m": 9.0,  "sc": 2.4, "color": Color(1.0, 0.3, 0.0), "xp": 22, "dmg": 2, "dist": 0, "gold": 32},
"boss_frost":     {"spd": 40, "hp_m": 12.0, "sc": 2.6, "color": Color(0.4, 0.7, 1.0), "xp": 24, "dmg": 2, "dist": 0, "gold": 35},
"boss_lightning": {"spd": 65, "hp_m": 8.0,  "sc": 2.2, "color": Color(0.9, 0.9, 0.2), "xp": 25, "dmg": 3, "dist": 0, "gold": 35},
```

### 类型判定扩展

在 `_physics_process` 中，现有的 `enemy_type == "boss"` 判断需要扩展为：

```gdscript
var _is_boss_type = (enemy_type in ["boss", "boss_fire", "boss_frost", "boss_lightning"])
var _is_boss_or_mini = (_is_boss_type or enemy_type == "miniboss")
```

### Boss 特殊行为分支

在 Boss 行为分支中，根据 `enemy_type` 执行不同的元素特殊逻辑：

```gdscript
if _is_boss_type:
    # 公共 Boss 行为（追踪、阶段射击、螺旋弹、狂暴连发）
    _process_common_boss(delta, dir, actual_speed, dist)

    # 元素特殊行为
    match enemy_type:
        "boss_fire":
            _process_fire_boss(delta)
        "boss_frost":
            _process_frost_boss(delta)
        "boss_lightning":
            _process_lightning_boss(delta)
```

### 阶段切换特效差异化

```gdscript
func _on_phase_change():
    var effect_color = ENEMY_TYPES[enemy_type].color
    Effects.death_burst(position, effect_color)
    phase_changed.emit(phase)

    match phase:
        1:
            base_speed *= _get_phase1_speed_mult()
        2:
            base_speed *= _get_phase2_speed_mult()
            _shoot_spiral(12)

func _get_phase1_speed_mult() -> float:
    match enemy_type:
        "boss_fire":      return 1.25
        "boss_frost":     return 1.15
        "boss_lightning": return 1.3
        _:                return 1.2   # 基础 boss

func _get_phase2_speed_mult() -> float:
    match enemy_type:
        "boss_fire":      return 1.20
        "boss_frost":     return 1.13
        "boss_lightning": return 1.15
        _:                return 1.17  # 基础 boss
```

### 子弹元素标识

为 EnemyBullet 增加 `element` 属性：

```gdscript
# EnemyBullet.gd
var element = ""  # "", "fire", "frost", "lightning"

func activate(pos, dir, elem = ""):
    element = elem
    # ... 现有逻辑
```

Player 命中时根据子弹 element 触发对应状态效果：

```gdscript
# Player.gd - 受弹命中时
if bullet.element == "fire":
    apply_burn()
elif bullet.element == "frost":
    apply_slow(0.3, 2.0)
elif bullet.element == "lightning":
    apply_stun(0.3)
```

## 数值平衡对比

| 属性 | 基础 Boss | 火焰 Boss | 冰霜 Boss | 雷电 Boss |
|------|----------|----------|----------|----------|
| 定位 | 均衡 | 进攻型 | 控制型 | 机动型 |
| 速度 | 50 | 55 (+10%) | 40 (-20%) | 65 (+30%) |
| HP倍率 | 10.0 | 9.0 (-10%) | 12.0 (+20%) | 8.0 (-20%) |
| 体型 | 2.4 | 2.4 | 2.6 (+8%) | 2.2 (-8%) |
| 接触伤害 | 2 | 2 | 2 | 3 (+50%) |

### 平衡说明

- **火焰 Boss**：比基础 Boss 更具侵略性，但血量稍低。燃烧区域迫使玩家持续移动，但不会像冻结那样剥夺玩家的操控权。
- **冰霜 Boss**：血量最高、体型最大，但速度最慢。冻结脉冲是高威胁技能但有 1s 蓄力预警，给予玩家反应窗口。冰甲增加了有效血量。
- **雷电 Boss**：速度最快、伤害最高但最脆弱。闪现机制使玩家难以保持安全距离，链式闪电增加了弹幕复杂度。高 XP 掉落作为高难度的补偿。
